## 四个概念，从下往上

一天消耗的热量由四块组成，理解它们才能理解"为什么我吃得不多还是胖"。

| 组成 | 占全天总消耗 | 说明 |
|---|---|---|
| **BMR（基础代谢率）** | 60%~70% | 躺着不动一天消耗的热量，维持呼吸、心跳、体温 |
| **TEF（食物热效应）** | 约 10% | 消化吸收食物本身消耗的热量 |
| **活动消耗（NEAT）** | 15%~30% | 走路、做家务、上下班、坐立不安的小动作 |
| **运动消耗（EAT）** | 5%~15% | 正式训练消耗的热量，比多数人想象的少得多 |

**TDEE（每日总消耗）= BMR + TEF + NEAT + EAT**

两个反直觉的结论：
1. **运动消耗占比很小**：一次力量训练约消耗 200~400 千卡，一杯奶茶就能补回来
2. **NEAT 波动很大**：减脂期人会不自觉地少动（少走、少站），这可能抵消掉你辛苦制造的缺口

## BMR 怎么估：Mifflin-St Jeor 公式

目前临床与运动营养领域最常用的估算式（1990 年提出，比更早的 Harris-Benedict 更准）：

```
男性：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 5
女性：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 − 161
```

**算例一**：身高 182 cm、体重 64 kg、22 岁男性
```
BMR = 10×64 + 6.25×182 − 5×22 + 5
    = 640 + 1137.5 − 110 + 5
    = 1672.5 ≈ 1672 千卡
```

**算例二**：身高 165 cm、体重 58 kg、25 岁女性
```
BMR = 10×58 + 6.25×165 − 5×25 − 161
    = 580 + 1031.25 − 125 − 161
    = 1325 千卡
```

## 从 BMR 到 TDEE：活动系数

| 活动水平 | 系数 | 说明 |
|---|---|---|
| 久坐 | 1.2 | 办公室工作，几乎不运动 |
| 轻度活动 | 1.375 | 每周训练 1~3 次 |
| 中度活动 | 1.55 | 每周训练 3~5 次 |
| 高度活动 | 1.725 | 每周训练 6~7 次 |
| 极高 | 1.9 | 体力劳动 + 每天训练 |

接前面的算例一，按 1.375（每周 3 练）：
```
TDEE = 1672 × 1.375 ≈ 2300 千卡
```

**⚠️ 活动系数最容易选高**。一个每周练 3 次、其余时间坐办公室的人，
选 1.55 就会把 TDEE 高估 200~300 千卡，然后"按计划吃却一直涨体重"。

## 目标热量：在 TDEE 上加减

| 目标 | 相对 TDEE | 2300 千卡的人 |
|---|---|---|
| 增肌（lean bulk） | +10%~20% 或 +200~400 千卡 | 2500~2700 |
| 维持 | ±0 | 2300 |
| 减脂（温和） | −300~500 千卡 | 1800~2000 |
| 减脂（激进，不推荐长期） | −500~800 千卡 | 1500~1800 |

减脂缺口不建议超过 **800 千卡/天**：缺口越大，肌肉流失比例越高，基础代谢下调越明显，
而且极难坚持，最后常以暴食反弹收场。

## ⚠️ 公式只是起点，必须用体重反馈校正

公式算出来的是**估计值**，个体差异可达 **±15%**（甲状腺功能、NEAT、食物吸收率、
甚至肠道菌群都会影响）。正确用法是"算一个起点，用趋势修正"：

1. 按估算值吃 **2 周**，每天称重（早晨空腹、上完厕所，每周取 3 次平均）
2. 看**周平均体重**的变化：
   - 增肌目标下两周完全不动 → 每天加 150~200 千卡
   - 增重快于每周 0.5% 体重 → 每天减 150~200 千卡
   - 减脂目标下两周没掉 → 每天减 150~200 千卡（或加 2000 步）
3. 每次只调 **150~200 千卡**，调完再观察两周

**为什么看周平均而不是每天**：一天之内体重波动 1~2 公斤很正常（水分、食物残留、糖原、
盐分）。盯着单日数字调整热量，只会被噪声牵着走。

## 三个常见误区

**① "我吃得很少但还是不瘦"**
绝大多数情况下是**实际摄入被低估**：烹饪油（一勺 90 千卡）、饮料、零食、酱料、
"尝一口"的菜都容易被漏记。解决办法是连续记录三天**所有入口的东西**，包括油和调味品。

**② "代谢慢是天生的"**
真正由疾病导致的代谢异常很少见。更常见的是：长期极端节食导致 BMR 下调、
NEAT 下降（不自觉地少动）、以及"记录失真"。三条叠加，就会产生"喝水都胖"的错觉。

**③ "运动了就可以多吃"**
一次力量训练约 200~400 千卡，一次 30 分钟慢跑约 250~350 千卡。
一块蛋糕、一杯奶茶就能全部抵消，还可能超出。**减脂的主要杠杆是吃，不是练。**
