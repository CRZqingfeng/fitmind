## 四个概念，从下往上

1. **BMR（基础代谢率）**：躺着不动一天消耗的热量，
   占全天总消耗的 60%~70%
2. **TEF（食物热效应）**：消化吸收食物本身要消耗的热量，
   约占摄入的 10%
3. **活动消耗**：走路、做家务、上下班这些零散活动
4. **运动消耗**：正式训练消耗的热量，
   **对多数人来说只占全天总消耗的 5%~15%**（比想象的少得多）

**TDEE（每日总消耗）= BMR + TEF + 活动消耗 + 运动消耗**

## BMR 怎么估（Mifflin-St Jeor 公式）

```
男性：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 5
女性：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 − 161
```

例：身高 182 cm、体重 64 kg、22 岁男性
→ BMR = 640 + 1137.5 − 110 + 5 ≈ **1672 千卡**

## 从 BMR 到 TDEE：活动系数

| 活动水平 | 系数 | 说明 |
|---|---|---|
| 久坐 | 1.2 | 办公室工作，几乎不运动 |
| 轻度活动 | 1.375 | 每周训练 1~3 次 |
| 中度活动 | 1.55 | 每周训练 3~5 次 |
| 高度活动 | 1.725 | 每周训练 6~7 次 |
| 极高 | 1.9 | 体力劳动 + 每天训练 |

上例按 1.375（每周 3 练）→ TDEE ≈ **2300 千卡**

## 目标热量

| 目标 | 相对 TDEE |
|---|---|
| 增肌（lean bulk） | +200 ~ +400 千卡 |
| 维持 | ±0 |
| 减脂 | −300 ~ −500 千卡 |

上例：增肌目标 ≈ **2500~2700 千卡/天**。

## ⚠️ 公式只是起点，必须用体重反馈校正

公式算出来的是**估计值**，个体差异可以到 ±15%。正确用法：

1. 按估算值吃 **2 周**，每天称重（早晨空腹，每周取 3 次平均）
2. 看**周平均体重**的变化趋势：
   - 增肌目标下体重两周完全不动 → 每天加 150~200 千卡
   - 体重涨得比目标快（每周超过 0.5% 体重）→ 每天减 150~200 千卡
   - 减脂目标下两周没掉 → 每天减 150~200 千卡
3. 每次只调 150~200 千卡，调完再观察两周

**为什么要看周平均而不是每天**：体重一天之内波动 1~2 公斤很正常
（水分、食物残留、糖原）。盯着单日数字调整热量，只会被噪声牵着走。

## 一个常见误区

"我吃得很少但还是不瘦" —— 绝大多数情况下是**实际摄入被低估**：
烹饪油、饮料、零食、酱料都容易被漏记。
解决办法是**连续记录三天所有入口的东西**，包括油和调味品。
