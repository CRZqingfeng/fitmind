## 通用原则：先控制，再加重量

所有动作都遵守同一条：**能在全程保持姿势不变形的重量，才是你的训练重量**。

判断"控制"的三个标准：
1. **离心可控**：下放阶段能用 2~3 秒匀速完成，而不是"掉下去"
2. **轨迹稳定**：从侧面看，杠铃/哑铃的路径接近一条直线或有规律的弧线
3. **没有代偿**：不靠腰部猛甩、不靠身体摆动、不耸肩

下面每个动作按 **起始 → 执行 → 呼吸 → 常见错误 → 自检 → 进阶/退阶** 展开。

## 高脚杯深蹲（居家哑铃版）

练股四头肌、臀部与核心，是新手学深蹲模式最安全的入口——
负重在前，躯干自然会保持直立，不容易弓腰。

**起始**
- 站位与肩同宽或略宽，脚尖外展 15~30 度（找到"蹲下去膝盖不别扭"的角度）
- 双手捧住一只哑铃的一端，贴住胸口（像捧一个球）
- 挺胸、收下巴、核心收紧（想象有人要打你肚子）

**执行**
1. 先**屈髋**把屁股往后下方送，同时屈膝
2. 膝盖**沿着脚尖方向**移动，允许略微超过脚尖（超过不是错，内扣才是错）
3. 下蹲到大腿与地面接近平行；活动度够就继续往下，不够不必强行
4. 底部停 0.5 秒，全程保持背部中立
5. 脚掌整体发力站起，顶端不要过度挺腰

**呼吸**：下蹲吸气、站起呼气；重量大时用瓦氏呼吸（憋气发力，站直后呼）。

**常见错误与纠正**

| 错误 | 原因 | 纠正 |
|---|---|---|
| 膝盖内扣 | 臀中肌弱 / 足弓塌 | 想"把地面撕开"，加侧向抬腿、蚌式开合 |
| 脚跟离地 | 踝背屈受限 | 垫 2~3 cm 小杠铃片，或先做踝关节活动 |
| 下蹲弓腰（屁股眨眼） | 髋活动度不足 / 蹲太深 | 缩小幅度到"腰开始弯之前"那一点 |
| 上身过度前倾 | 核心不稳 / 负重太靠前 | 哑铃贴紧胸口，先减重量 |

**自检**：侧面录像，看两件事——膝盖是否沿着脚尖方向、脊柱是否是一条直线（不是"弯一下再直"）。

**进阶**：高脚杯深蹲 → 双哑铃前蹲 → 杠铃后蹲。
**退阶**：箱式深蹲（坐到箱子再起）、扶墙深蹲。

## 哑铃卧推

练胸大肌、三角肌前束、肱三头肌。哑铃版本活动轨迹更自由，对肩更友好，
是肩关节有不适史的人的首选。

**起始**
- 坐在凳端，哑铃竖放在大腿上，靠"躺下 + 用大腿顶"把哑铃送到胸部两侧
- **肩胛骨先下沉再后缩**：想象把肩胛骨夹住一支笔，并把它压向凳子，全程保持
- 双脚踩实地面，臀部贴凳，腰下保留自然弧度（不是刻意拱成桥）

**执行**
1. 手肘与躯干约 **45~60 度**（不要完全打开成 90 度，那样肩关节前侧压力骤增）
2. 下放到哑铃与胸部同高、前臂接近垂直地面
3. 想"把哑铃推向天花板"，同时让两只哑铃轻轻靠拢（不碰撞）
4. 顶端不要锁死肘关节，保持一点张力

**呼吸**：下放吸气，推起呼气。

**常见错误**

| 错误 | 后果 | 纠正 |
|---|---|---|
| 塌肩（肩胛前伸） | 肩峰撞击、前侧疼 | 每次下放前重做一次"下沉 + 后缩" |
| 手肘 90 度外展 | 肩关节压力大 | 收到 45~60 度，像"箭头"而不是"T" |
| 推起时臀部离地 | 变成"下斜卧推"，胸部刺激减少 | 降重量，脚踩实 |
| 哑铃在胸口弹一下 | 失去张力，肩部受冲击 | 底部停 0.5 秒 |

**自检**：从上方拍，看两只哑铃是否对称、手腕是否中立（不要向后折）。

**变式**：上斜 30 度（更多上胸）、中立握（对肩最友好）、地板卧推（限制幅度，适合肩不适者）。

## 罗马尼亚硬拉（RDL）

练臀大肌与大腿后侧（腘绳肌）最重要的动作之一，也是"学会髋铰链"的核心。

**起始**
- 站直，双脚与髋同宽，哑铃/杠铃贴住大腿前侧
- 膝盖**微屈并固定**（约 15 度），全程角度基本不变
- 肩胛后收，杠铃贴近身体

**执行**
1. **屁股向后推**（像用屁股去关身后的门），躯干随之向前倾
2. 哑铃贴着腿往下滑，重心保持在脚中部
3. 下放到**大腿后侧有强烈拉伸感**就停（通常到膝盖下方，不必触地）
4. 臀部发力把身体"顶"回站直，顶端夹臀但不要过度后仰

**关键感受**：大腿后侧被拉长、发紧；**不是腰部发力**。

**常见错误**

| 错误 | 判断 | 纠正 |
|---|---|---|
| 弓背 | 侧面看脊柱弯了 | 减重量，缩小幅度，先练髋铰链（徒手顶墙） |
| 用腰把重量拉起来 | 第二天腰酸而不是腿后侧酸 | 想"脚踩地、屁股往前顶" |
| 膝盖大幅弯曲，变成硬拉 | 下放时膝盖越弯越多 | 固定膝角，只动髋 |
| 幅度过大追求触地 | 骨盆后倾、腰椎受力 | 到"拉伸感最强"就停 |

**自检**：练完第二天，酸的位置应该在**大腿后侧和臀部**。如果酸在腰部，先减重量。

**进阶**：双哑铃 RDL → 杠铃 RDL → 单腿 RDL（平衡与稳定性）。

## 单臂哑铃划船

练背阔肌、斜方肌中下部、菱形肌，是"练背"最基础的动作。

**起始**
- 一只手和**同侧膝盖**撑在椅子或床上，另一只脚踩地
- 背部保持水平（不要塌腰、不要转头看）
- 哑铃自然垂在肩下方，肩胛先"放下去"（不要耸肩）

**执行**
1. 肘部**贴近身体**向后拉，想着"用肘部把哑铃拉向髋部"，而不是"用手把哑铃提起来"
2. 顶端肩胛骨向后夹一下，停 0.5 秒
3. 下放用 2 秒，让肩胛自然前伸（拉开背阔肌）

**常见错误**

| 错误 | 后果 | 纠正 |
|---|---|---|
| 用手臂甩 | 练成肱二头肌 | 想"肘领先、手跟随" |
| 身体旋转借力 | 腰椎剪切力大 | 降重量，核心收紧，肩膀保持水平 |
| 耸肩 | 斜方肌上部代偿 | 先"沉肩"再拉 |
| 幅度太短 | 背阔肌没被拉长 | 下放到底，允许肩胛前伸 |

**自检**：把手放在背阔肌上，感受它是否在收缩；如果只有手臂酸，说明发力顺序错了。

## 引体向上

练背最有效的自重动作，也是很多人的"卡点"。

**技术要点**
- 握距略宽于肩，正握（掌心朝前）
- **启动先沉肩**：肩胛骨向下向后收，再用手肘往下拉
- 想"把胸口拉向单杠"，而不是"把下巴够过杠"
- 下放到手臂接近伸直（保留一点张力）

**做不到完整引体怎么办**（按推荐顺序）：
1. **离心引体**：跳上去，用 3~5 秒慢慢放下来，做 5 组 × 3 次
2. **弹力带辅助引体**：选能完成 6~8 次的阻力
3. **高位下拉**：作为力量积累，重量能加到体重的 60%~70% 再回到引体

**常见错误**：耸肩、靠身体摆动借力（kipping 是另一个动作，不是引体）、只做下半程。

## 动作之外：三个容易被忽略的细节

1. **握法与手腕**：卧推/俯卧撑时手腕保持中立，不要向后折；杠铃压在掌根而不是手指
2. **呼吸与腹压**：大重量复合动作先吸气收紧核心再发力，站直后呼气
3. **训练日志**：记录每个动作的重量 × 次数 × 组数。没有记录就没有渐进超负荷
